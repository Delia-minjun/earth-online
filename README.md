# 地球 Online

个人使用的「地球 Online」——把 Excel 周计划表变成能自动汇总、能自己记账、能给自己发币的系统。当前阶段：**P3 完成**（核心闭环 / 记录类 / 奖惩经济 / 番茄钟）。

> 想直接试用？跳到 [保姆级安装与使用](#保姆级安装与使用)。

## 目录结构

| 目录 | 用途 |
|---|---|
| `01-需求` | 需求规格文档、变更记录、待确认清单 |
| `02-设计` | 界面草图、流程图、图标 |
| `03-数据模型` | 表结构、字段定义、关系说明 |
| `04-技术方案` | 技术选型、阶段计划、部署与备份策略 |
| `05-开发` | 源代码（Node + Hono + SQLite 服务端 / React + Vite 前端） |
| `06-素材` | 术语对照表、参考资料 |

## 现在能做什么

| 模块 | 能力 |
|---|---|
| 日程 | 「今日 / 本周 / 本月」三段；右侧固定时间轴；给任意一天加日程（可带备注）；点日期看当天任务 |
| 任务 | 优先级、DDL（四档紧急度配色）、过期自动顺延并标注延迟、完成后发币 |
| 习惯 | 每日打卡、14 天网格、连续 7 天额外奖励 |
| 记录 | 记账（分类/预算）、体重与 30 天曲线、锻炼（一天多条）、饮食、随手记 |
| 课表 | 手动录入 / 截图导入（DeepSeek 视觉）、单双周、教学周过滤、冲突检测 |
| 复盘 | 四象限（保持/改进/停止/开始）+ 四张数据卡 + 时间分配环形图，写满四项发币 |
| 奖惩 | 钱包、自定义奖赏商店（不允许透支）、六领域进度条（每日 −1%，下限 40%） |
| 番茄钟 | 25/45/60/正计时、绑定任务、完成确认才记录、结束自动写时间块并发币 |
| 双语 | 中文 / English 一键切换 |
| 其它 | 离线状态提示、深色图标、桌面快捷方式 |

## 保姆级安装与使用

> 只写 Windows。照着做就行，不需要事先会用命令行。

### 第 0 步：确认你的电脑

- Windows 10 或 11，64 位（基本都满足）
- 磁盘留出 500 MB
- 不需要显卡、不需要联网账号（除了第一次下载）

### 第 1 步：认识「命令行」是什么、怎么打开

命令行就是一个黑底白字的窗口，你在里面打字按回车，电脑照着做。三种打开方式，任选一种：

1. **最快**：按键盘 `Win` 键（有窗户图标的那个）+ `R`，弹出小窗口，输入 `cmd`，回车。
2. 点屏幕左下角「开始」，直接打字 `cmd`，回车。
3. 打开任意文件夹，点一下上方的**地址栏**（显示路径的那一栏），把里面的字删掉，输入 `cmd`，回车 —— 这样打开的命令行**自动就在这个文件夹里**，第 4 步会用到。

> 复制粘贴：在命令行里右键就是粘贴（`Ctrl+V` 也行）。

### 第 2 步：装 Node.js（唯一要装的软件）

1. 打开浏览器，访问 **https://nodejs.org/zh-cn**
2. 点绿色大按钮下载 **LTS** 版本（写着 22.x 的那个 `.msi` 文件）
3. 双击下载好的文件 → `Next` → 勾上同意 → `Next` → `Install` → `Finish`
4. **把之前开的命令行窗口全关掉**，重新开一个（很重要，旧窗口读不到刚装的程序）
5. 在黑窗口里输入：

```bat
node -v
```

回车后应该显示类似 `v22.11.0`。显示 `'node' 不是内部或外部命令` 就说明没装好或没重开窗口。

### 第 3 步：把程序下载到电脑上

**方式 A（不用装 git，推荐）**

1. 打开 https://github.com/Delia-minjun/earth-online
2. 点右边绿色的 `Code` 按钮 → `Download ZIP`
3. 下载完是一个压缩包，右键 → **全部解压**
4. 把解压出来的文件夹挪到一个你找得到的地方，比如 `D:\地球Online`

**方式 B（已装 git 的人）**

```bat
git clone https://github.com/Delia-minjun/earth-online.git D:\地球Online
```

### 第 3.5 步（懒人选项）：双击「安装.cmd」一步到位

如果你不想敲命令，直接进 `地球Online\地球Online\05-开发`，**双击 `安装.cmd`**。它会自动做完后面第 4–7 步，并额外做三件事：

- 在**桌面**建一个「地球 Online」快捷方式
- 在**开机启动**里也放一个（静默启动，不弹浏览器）
- 注册**每天凌晨 4 点自动更新**

装完它会自己起服务并打开浏览器。以后你就只双击桌面图标。

> 如果不想要开机自启：按 `Win+R` 输入 `shell:startup`，把里面的「地球 Online」快捷方式删掉即可。
> 想取消自动更新：`Win+R` 输入 `taskschd.msc`，任务计划程序里删掉 `EarthOnlineAutoUpdate`。

**手动安装（想看清楚每一步）继续往下：**

### 第 4 步：在「正确的那层文件夹」打开命令行

这一步最容易错。程序在 `地球Online\05-开发` 这一层，命令行必须开在这一层。

1. 用资源管理器一层层点进去：`D:\地球Online\地球Online\05-开发`
2. 点上方**地址栏**，删掉里面内容，输入 `cmd`，回车
3. 在黑窗口里输入 `dir` 回车，**应该能看到 `package.json`、`start.cmd`、`apps`**
   - 看不到就说明进错文件夹了，回到第 1 小步重来

### 第 5 步：装依赖（一次性，1–3 分钟）

在黑窗口里依次输入（每行按一次回车，等上一行跑完再输下一行）：

```bat
corepack enable
pnpm install
```

- 第一行是打开 pnpm（包管理器），只需要做一次
- 第二行会下载一堆文件，滚很多行是正常的，最后出现 `Done` 就好
- 如果提示 `pnpm 不是内部或外部命令`：关掉窗口重开，再试一次；还不行就输入 `npm i -g pnpm` 再试

### 第 6 步：构建前端（1–3 分钟）

```bat
pnpm build
```

最后一行出现 `✓ built in x.xxs` 就成功了。这一步把界面打包成浏览器能看的东西。

### 第 7 步：启动

```bat
pnpm start
```

看到这两行就成了：

```
[earth-online] listening on http://127.0.0.1:7788
[earth-online] db:     data\life.db
```

**这个黑窗口不要关**，关了服务就停了。然后打开浏览器，地址栏输入：

```
http://127.0.0.1:7788
```

> 以后启动更省事：直接双击 `05-开发\start.cmd`，它会自动开浏览器。

### 第 8 步：第一次打开会自动出现引导

第一次打开会自动弹一个 6 步的引导：目标部位亮着、其它地方变灰，点灰的地方或「下一步」继续。

**想再看一遍**：左侧「设置」→ **引导教程** → 「重新看一遍」。
（侧栏底部那个小 `?` 也能重看。）

### 第 9 步：按引导填自己的东西

1. 「设置」→ **学期开学日**：填这学期第一周的周一（决定"第几周"；不填就显示全部课程）
2. 「设置」→ **作息时间**：第 1 节几点开始、每节多少分钟、课间几分钟
3. 「日程 → 本周」右上 **编辑课表**：手动加课，或上传课表截图自动识别（要在设置里填 AI Key）
4. 「日程 → 今日」→ 习惯卡片右上 **管理**：加几个想坚持的习惯
5. 首页 **奖赏商店** 右上 `＋`：建自己的奖赏，比如"一杯奶茶 30 币"

### 第 10 步：每天怎么用

| 想做的事 | 点哪里 |
|---|---|
| 看今天要干什么 | 日程 → 今日 |
| 加一件事 | 任务卡片下方的输入框 |
| 给任务设截止日 | 任务右边的 `DDL` → 系统日历里选日期 |
| 打习惯卡 | 今日 → 习惯，点一下名字 |
| 记钱 / 体重 / 锻炼 / 吃饭 | 今日页对应卡片 |
| 专注 25 分钟 | 右侧时间轴标题旁的 ◷ |
| 排下周、看整月 | 日程 → 本周 / 本月 |
| 周日回顾 | 复盘（四个格子都写满发 10 币） |
| 兑奖赏 | 首页商店里点「兑换」 |

### 第 11 步：怎么关、怎么再开

- **关**：直接关掉那个黑窗口（或窗口里按 `Ctrl+C`）
- **再开**：双击 `05-开发\start.cmd`
- 建议右键 `start.cmd` → 发送到 → 桌面快捷方式，以后双击桌面图标即可

### 第 12 步：数据在哪、怎么备份

- 所有数据都在一个文件里：`05-开发\data\life.db`
- **备份**：关掉服务，把这个文件复制到网盘或 U 盘（文件名可以改成 `life-2026-11-13.db` 记住日期）
- **恢复**：关掉服务，把备份文件改回 `life.db` 覆盖回去，再启动
- 换电脑：装好程序后，把这个文件拷到新电脑同位置即可

### 第 13 步：更新到新版本

三种方式，任选：

1. **什么都不用做**：装了计划任务的话，每天凌晨 4 点自动拉取更新并重启（见下文）
2. **双击 `05-开发\更新.cmd`**：拉代码 → 装依赖 → 构建，然后提示你重启
3. **手动**：命令行里依次 `git pull` → `pnpm install` → `pnpm build` → 重启

### 常见问题（照着对）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `'node' 不是内部或外部命令` | 没装 Node，或装完没重开窗口 | 重装 Node，然后**关掉所有黑窗口重开** |
| `'pnpm' 不是内部或外部命令` | corepack 没生效 | 重开窗口；还不行跑 `npm i -g pnpm` |
| `ERR_PNPM_...` 一堆红字 | 依赖下载失败 | 换网络/开代理重试 `pnpm install --force` |
| `EADDRINUSE: 7788` | 已经有一个实例在跑 | 关掉旧的黑窗口，或任务管理器里结束 node.exe |
| 浏览器白屏 | 没构建或构建失败 | 重新 `pnpm build`，再刷新（Ctrl+F5） |
| 页面还是旧样子 | 浏览器缓存/没重启 | `pnpm build` → 重启服务 → Ctrl+F5 |
| 中文乱码 | 用了别的终端 | 用 `start.cmd` 启动（它设了编码） |
| 双击 zip 里的 start.cmd 没反应 | 没解压就在压缩包里点 | 先「全部解压」，再到解压后的文件夹里点 |
| 杀毒软件拦截 | 未签名的本地程序 | 允许运行即可，数据都在你自己电脑上 |

## 把改动同步到 GitHub（自动更新）

三件事分开看：

### ① 提交推送：双击 `05-开发\同步.cmd`

它做 `git add -A` → 用时间戳提交 → `git push origin main`。没有改动会直接提示"没有新改动"。

### ② 自动检查：GitHub Actions

`.github/workflows/ci.yml` 会在**每次 push / PR 时自动跑**：装依赖 → 类型检查（server + web）→ 47 个测试 → 构建前端。

跑失败会在提交记录旁边打叉，点进 Actions 能看到哪一步挂了。仓库首页还能挂个状态徽章：` https://github.com/Delia-minjun/earth-online/actions/workflows/ci.yml/badge.svg `

### ③ 全自动更新（已装好）

Windows 计划任务 `EarthOnlineAutoUpdate` 每天 **04:00** 跑 `05-开发\自动更新.cmd`，它做：

```
git fetch → 对比本地与 origin/main
  └ 一样：记一行日志，退出
  └ 不一样：git pull --ff-only → pnpm install → pnpm build
             → 关掉 7788 上的旧进程 → 静默重启服务
```

日志在 `05-开发\logs\auto-update.log`（只记时间、版本号、成功/失败）。

手动跑一次：双击 `05-开发\自动更新.cmd`。查任务：`schtasks /Query /TN EarthOnlineAutoUpdate`。

> 注意：任务设置是 **Interactive only**，即只在你登录 Windows 时才会触发（服务本来就跑在你的会话里，这样最稳）。
> 如果某天拉取失败（比如你在本地改了一半没同步），脚本会**跳过这次更新并保留旧版本继续跑**，不会把服务弄挂。

### 怎么看引导

第一次打开会自动弹 6 步引导（高亮部位、其余变灰，点页面任意处或「下一步」推进）。
看过了就不再弹；想再看，点侧栏底部那个 **?**。


### 关于"全自动"的边界

- **代码同步**：全自动（计划任务每天拉取 + 重建 + 重启）
- **写新功能**：不可能自动——那得有人写代码并推送
- 所以你的日常是：改完 → 双击 `同步.cmd` 推上去 → 另一台机器（或这台机器第二天凌晨）自己更新到最新

## 开发约定（改代码前必读）

1. **先定位根因，再动手。** 任何修改或 bug 修复，必须先说清楚「为什么会这样」——哪个文件、哪一行、在什么条件下触发、怎么复现。解释与复现对得上，才允许改代码。
   - 禁止试错式连续打补丁：**连续两次没修好，说明根因还没找到**，停下来重新定位，而不是再试一版。
   - 反例：三列布局连改三版都没生效，前两版都在猜宽度阈值，真正原因是 Tailwind 把 `min-[1150px]:` 排在 `lg:` 之前导致规则被覆盖。
2. **改完必须三件事都能过**：`typecheck`（server + web）、测试（47 个用例）、`vite build`。
3. **测试文件必须分开进程跑**（每个文件用自己的临时库），合并跑会互相污染数据。
4. **界面改动要在浏览器里刷新确认**，不能只凭代码判断生效。
5. **不碰用户真实数据做测试**：测试一律用临时目录，清理干净再收工。
6. 文档跟着代码走：改了行为就同步改需求/技术方案/README，不要让文档落后于实现。
7. **端口固定 `7788`，不要改。** 任何情况下都只跑一个实例，跑在 7788 上。
8. **重启服务的固定流程**（改完服务端代码时必须走一遍）：
   1. 先提示用户关闭他自己开的那个黑窗口（`start.cmd` / 桌面图标起的）；
   2. 确认 7788 已释放（`netstat -ano | findstr :7788` 无 LISTENING）；
   3. 由助手启动服务；
   4. 启动后必须验证：`/api/health` 返回 ok，且**新功能确实加载**（例如新字段出现在返回里），不能只看进程还活着。
   - 反例：有次验证全返回 `undefined`，以为是代码写错，实际是请求打到了用户自己开的旧实例上——旧进程没关，新进程 `EADDRINUSE` 起不来，健康检查却照样通。
9. **新功能优先用弹窗，不要往页面里塞。** 如果新功能是"在已有功能上继续加"（比如给任务加 DDL、给课程加周次），一律做成弹窗/抽屉，从现有按钮打开；**不改变原页面的布局与视觉节奏**。
   - 判断标准：加了新功能之后，原来那屏的卡片数量、排列、留白不应该变。
   - 反例：DDL 第一版直接插在输入框下面展开一行日期选择器，把「今日任务」的行高撑开了；后来改成弹窗才回到原样。
   - 例外：只有当新功能本身就是页面主体（比如整个新页面）时，才不用弹窗。
10. **行内操作按钮一律垂直居中。** 列表行里的 `＋` / `×` / `改` / `DDL` 这类小按钮，必须相对**整行内容**垂直居中，不能只贴在标题那一行。
   - 做法：把按钮作为行容器的直接子元素并加 `self-center`；不要塞进"标题那一行"的 flex 里。
   - 判断标准：行内容变成两行（标题 + 副标题）时，按钮仍在中间。

## 需求速览

1. 以「周」为单位的计划系统，承接原 Excel 周计划表的全部 15 个功能块。
2. 三端同步：电脑（主工作台）+ 平板（纸张替代）+ 手机（打卡 / 记一笔 / 看今天）。
3. 学习 Agent：分科建档、OCR + 校对、间隔重复复习、考前模拟与背记卡片。
4. 奖惩经济：做实事赚虚拟币，用币兑换自己定的奖赏；进度条会衰减，但不扣币、不负债。
5. 中英双语：一键切换，AI 内容跟随界面语言；点词查义 + 生词本 + 术语对照表。
6. 离线优先：打卡、随手记、记账、体重可离线写，联网自动合并。
7. 本地部署：先跑在本机，架构预留上云余地。

## 关键约束

- 数据在自己手里，可导出、可备份。
- 游戏化不能影响真实数据；惩罚只作用于进度条。
- 界面英文人工撰写，不机翻。
- i18n 从第一版就做，不做事后补。

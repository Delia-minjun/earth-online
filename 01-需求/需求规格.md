# 人生管理系统 · 需求文档

---

## 0. 一句话定位

这是一个**单人使用的人生管理系统**：三端同步、不用每周手动复制、能自动汇总；在此之上加一个**学习 Agent**（分科整理、复习、出题、模拟考）、一层**奖惩经济**（做实事赚币、用币兑换自己定的奖励、进度条会衰减），以及**中英双语**（界面即学习材料），让「坚持」有看得见的反馈。

交互与视觉方向见 §10：重新设计，简约清淡的莫兰迪色系，**不照搬表格**。

## 2. 关键设计决策

### 2.1 「周」是第一等实体

- 周起始固定周一；打开即本周；可跳任意历史周。
- 不需要手动复制：进入新周自动生成空白周，写入才有记录。
- 上周未完成的重点待办**提示顺延**，不自动搬运。
- 周、月、年三种并列视图（周视图为主战场）。

### 2.2 时间块取代「画格子」（两阶段）

一条时间块 = 日期 + 开始时间 + 时长 + 标题 + 类别（+ 备注），粒度 30 分钟，默认 06:00–24:00。

- **P1 列表录入**：按时间顺序的行，填「开始–结束 + 内容 + 类别」，不做拖拽。
- **P2 可视化时间轴**：30 分钟网格、拖拽拉伸、重叠高亮。数据模型不变，只换呈现层。

### 2.3 层级关系（做，但克制）

- **领域**固定 6 个：健康 / 学业事业 / 关系 / 财务 / 成长 / 娱乐。
- **项目**轻量：名称、状态、截止日，不做无限嵌套。
- **任务**是主力：挂项目或直接挂领域。
- 不做子任务、不做多级项目树。

### 2.4 记录类统一按「天」挂载

随手记、食谱、体重、心情、记账都以日期为主键；周视图只是它们的呈现。

### 2.5 记账范围

- 支出：默认 4 类（食品/出行/生活/娱乐），可增删；金额、备注、日期。
- 收入：来源类别 + 金额 + 日期。
- 预算：**月度总预算 + 可选分类上限**；周视图显示「本周累计 / 剩余」。

### 2.6 离线策略

| 离线可写 | 离线只读 |
|---|---|
| 习惯打卡、随手记、记账、体重、勾选待办、快速捕获 | 时间轴编辑、周复盘正文、预算汇总、学习模块 |

冲突原则：**不丢数据优先**。逐条记录天然幂等；文本块双端并改则保留两版并提示合并。

## 3. 三端需求

| 设备 | 定位 | 主要动作 |
|---|---|---|
| 电脑 | 主工作台 | 规划整周、编辑时间轴、写周复盘、看统计、整理学习资料 |
| 平板（横屏） | 纸张替代 | 时间轴 + 周复盘 + 刷题 |
| 手机 | 高频轻操作 | 今日看板、打卡、随手记、记账、体重、复习卡片 |

硬需求：三端同一份数据；离线记录联网后自动合并并标明状态；换设备登录即恢复；习惯打卡与复盘提醒。

**默认落地屏**：手机 = 今日；电脑/平板 = 本周。

**提醒**：习惯每日 21:00 汇总；周日晚 20:00 复盘；走手机端通知，全部可关。

**同步延迟目标**：同一网络内近实时；跨网络允许「当晚同步到」。

**汇合点（已定）**：先跑在这台电脑上，架构预留上云迁移余地。电脑关机时，手机离线数据等开机后同步。

## 4. 学习 Agent

**定位**：独立模块 + 全局入口，不侵入主数据。有自己的数据域（科目、资料、题目、复习记录），只通过三条线与主系统相连：

1. 生成的「复习任务」可一键排进周计划/时间轴；
2. 学习时长汇入统计与奖惩经济；
3. 考试日期 → 倒计时。

### 4.1 分科建档

- 科目树（科目 → 章节），支持多科目并行。
- 资料上传：PDF、PPT、Word、纯文本、图片、网页链接；**含手写扫描件**。
- **OCR + 校对**：扫描件先识别成文字 → 「待校对」→ 用户确认后才可用于出题。
- 自动处理：抽取文字 → 按章节切分 → 生成摘要、大纲、知识点卡片。
- 每份资料保留文件名与页码索引，供回答溯源。
- 资料状态：未学 / 已学 / 待复习 / 重点。

### 4.2 复习

- 知识点级间隔重复：新学 → 1 天 → 3 天 → 7 天 → 21 天（可调）。
- 今日复习队列：按到期时间 + 掌握度排序。
- 卡片式自测：正面问题、背面答案，自评三档（会 / 模糊 / 不会）。
- 错题本：做错的题 + 错因。
- 掌握度：按科目/章节显示百分比。

### 4.3 出题（两种形态，共用一套题目数据）

- **考前模拟**：按科目/章节范围生成整套卷子，设定题量与时长，计时作答，交卷出分、逐题解析、薄弱章节定位。
- **背记卡片**：正面问题/背面答案，接入 4.2 的间隔重复队列。
- 题型：单选、多选、填空、判断、简答。
- **只能基于已上传且已校对资料出题**，每题标注出处。
- 批改：客观题自动判；简答给评分 + 参考答案 + 扣分点。

### 4.4 约束与风险

- **幻觉**：答案以资料为准、必须可溯源；无资料时不生成题目。
- **OCR 误差**：必经人工校对。
- **资料敏感性**：校内课件上传到第三方 API 的接受度需确认。
- **成本**：开学初批量整理一次，之后只做增量。
- **离线**：学习模块一律要求联网。

## 5. 奖惩经济系统

**定位**：不做虚拟形象、不做养成载体。核心是一套**由真实行为驱动、奖赏自己定义**的小型经济。

### 5.1 三个组成

**① 挣（价目表，全部可自定义）**

| 行为 | 默认收益 |
|---|---|
| 完成一个任务（按预估时长折算） | 30 分钟 = 3 币 |
| 习惯打卡 | 2 币 / 次 |
| 习惯连续 7 天 | 额外 10 币 |
| 专注学习 25 分钟 | 3 币 |
| 完成一套模拟卷 | 15 币 |
| 周复盘 | 10 币 |
| 月复盘 | 30 币 |
| 全勤周 | 20 币 |

**② 花（奖赏商店，自己填）**

示例：奶茶 30、看一集剧 40、游戏 1 小时 60、买本书 150、周末出游 400。

- 先有币才能兑换，**不允许透支**。
- 每次兑换留在「账本」里。
- **兑换真实花销时自动记一笔支出**。

**③ 衰减（进度条）**

- 六个领域各一条进度条，由该领域行为累积。
- 无行为的日/周按比例回落；当日重点未完成会让对应进度条下滑。
- **只衰减进度条**：不影响已得虚拟币，不改动任何真实记录；永不负债。

### 5.2 设计红线

1. 币只能由系统按规则发放——**不提供「手动加币」按钮**。
2. 奖赏必须真实可得、价格合理。
3. 惩罚只作用于进度条，不羞辱、不清零历史。
4. 整个经济层可关闭。
5. 虚拟币与真实金钱严格分离。

### 5.3 与仪表盘的关系

同一份数据两种皮肤：仪表盘 = 数字报表；奖赏页 = 钱包、商店、进度条。

### 5.4 可调参数（用户自行设置）

- 衰减速度与下限（建议初始：每日 -1%，下限 40%）
- 各行为币值
- 奖赏清单与价格

## 6. 双语与英语学习

**定位**：不是普通的语言切换，而是让**界面本身成为学习材料**。

### 6.1 四层结构

| 层 | 内容 | 说明 |
|---|---|---|
| ① 界面语言 | 全部界面文案中/英切换 | 基础层，必须做 |
| ② 内容语言 | 系统生成的摘要、题目、复盘提示用哪种语言 | 跟随界面语言（v1.2 定） |
| ③ 学习辅助 | 点词查义、生词本、发音、术语对照 | 真正的学习层 |
| ④ 输出练习 | 用英文写复盘/日记，AI 批改 | 与 4.3 的批改能力共用 |

### 6.2 一键切换（v1.2 定）

- 两档：全中文 / 全英文；右上角一键切换，记住选择，即时生效不刷新。
- 不做中文比例调节。原「渐进沉浸」方案留作以后的可选项——只要语言不绑死在组件里，将来加比例只是配置项。
- 用户自己写的内容（任务标题、复盘正文、随手记）**永不翻译**。

### 6.3 内容语言跟随界面（v1.2 定）

- AI 生成的摘要、题目、解析、复盘引导，跟随界面语言。
- 例外：用户上传的原始资料保持原语言，不被「翻译」，只在需要时按需生成英文摘要。

### 6.4 点词入生词本（关键复用）

- 界面任意单词可点（或选中）→ 释义 / 音标 / 例句 → 一键加入生词本。
- 生词本自动进入 4.2 的间隔重复队列。
- **不新增模块**：复用复习卡片与复习引擎，只是多一种卡片类型。

### 6.5 术语对照表（可导入）

- 字段：英文 / 中文 / 释义 / 例句 / 分类 / 备注。
- **支持导入外部文档**：Excel、CSV、Word、Markdown；导入后可编辑、去重、合并。用户会自己整理一份术语表提交。
- 三个用途：①界面翻译的一致性来源；②点词查义的优先词库；③生词卡的释义与例句。
- 内置一份基础词条（时间块 Time Block、复盘 Review、连续天数 Streak、掌握度 Mastery、预算 Budget 等），导入的词条优先。

### 6.6 输出练习

- 复盘 / 随手记可切换到英文写作模式。
- AI 批改：语法、用词、地道表达；保留原稿与修改稿对照。
- 与 4.3 的批改能力共用，不重复建设。

### 6.7 架构约束（硬约束，影响开发顺序）

i18n 必须**从第一行代码就做**：所有文案集中在语言包，不硬编码进组件。事后补做是灾难级返工。因此双语不是「后期功能」，而是**第一版的开发方式**。

### 6.8 范围与质量

- 只做中文 + 英文，不做其他语言。
- 界面英文**必须人工撰写**，不机翻——机翻的界面会让人学到奇怪的表达。
- 英文用「日常、清晰、不文学化」的语气；专有名词在术语表里统一定译。

## 7. 数据与迁移

- 从空白开始。
- 导出功能不是必须的。
- 学习资料：本地存储，提供文件夹位置。
- 备份：自动、可恢复（建议每日一次快照）。

## 8. 明确不做

多用户协作与分享、社交功能、手环等健康设备自动同步、知识库与双链笔记、周计划内的图片附件、历史 Excel 导入、学习模块离线、虚拟形象与美术资产、用真钱购买虚拟币、子任务与多级项目树、单周打印导出（推迟）、中英以外的语言。

## 10. 视觉与体验原则

**方向**：重新设计，简约、清淡的莫兰迪色系；**不照搬表格**。

### 10.1 色板

| 用途 | 色值 |
|---|---|
| 页面底色 | `#F4F2EE`（暖白，不用纯白） |
| 卡片 | `#FFFFFF`，描边 `#E7E3DC` |
| 正文 / 次要 / 弱化 | `#33322F` / `#6E6B66` / `#A29E96` |
| 主色 | 灰绿 `#8FA38E` |
| 警示 | 灰陶红 `#C08B7D` |
| 五类事项 | 灰蓝 `#9BA7B0`、米黄 `#CBBB9A`、灰绿 `#A8B5A2`、灰紫 `#B0A6BC`、灰粉 `#C9A9A6` |

### 10.2 规则

1. 颜色只用于表达**类别与状态**，不做装饰。
2. 文字对比度不低于 4.5:1——莫兰迪低饱和，文字必须用深色兜底，否则「好看但看不清」。
3. **去表格线**：用间距与留白分组，不用边框画格。
4. **一屏一件事**：周 / 今日 / 复盘 / 学习 / 奖赏各自独立，不堆信息。
5. 时间块用「淡色底 + 左侧色条」；一天默认最多显示 4 块，其余折叠为「还有 N 项」。
6. 手机只放四件事：今日重点、接下来、习惯打卡、随手记。
7. 空位用「＋ 添加」浅色占位，不留纯空白。

### 10.3 原型

三张高保真图在 `02-设计/原型/`：周视图（桌面）、今日（手机）、奖赏（桌面），渲染脚本 `render_mockups.py` 可重复生成。
